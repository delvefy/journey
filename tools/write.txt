JOURNEY — THE RIDDLE-HOARD
==========================
How to write rooms. Read this whole file before adding one.


1. THE PREMISE — THE RULE OF THE WORLD
--------------------------------------
The world is a hoard of rooms, and every room IS a single word or number — the
answer to the riddle that let you in. You do not walk freely. Each room is
walled by four riddles; every riddle's answer is the NAME of the room on the
other side of that wall. Speak the name and the wall opens.

So the player's whole act is: read a riddle, find the one word it hides, type
it. A right answer is a door. The craft of this project is writing riddles
whose answer is exactly one word — the neighbour's name — and nothing else.


2. THE GRID AND THE ORDER OF WORK  (kept from the old Journey)
--------------------------------------------------------------
Rooms live on a 2D grid at  rooms/<x>/<y>.html  — x is the folder, y is the
file basename. (0,0) is the origin, the room named KEY.

Write rooms ONE AT A TIME, never in batches:
  - Write the room, save the HTML, update the LAST ROOM line in rooms-map.txt,
    and ONLY THEN start the next room. Saving each room before the next is what
    makes the work safe to interrupt.
  - "Write the next N rooms" = repeat that one-room loop N times (write, save,
    update tracker, proceed). "Write the next room" is just N = 1.
  - The next room is the unwritten coordinate CLOSEST to the origin (0,0):
    smallest straight-line distance; ties broken clockwise from north
    (N, NE, E, SE, S, SW, W, NW).
  - Written rooms therefore form one unbroken run outward from 0:0. The LAST
    ROOM line in rooms-map.txt pins exactly where we are.

The neighbour coordinate files, by direction, from a room at (x,y):
  North (x, y+1):  "<y+1>.html"          (same folder)
  South (x, y-1):  "<y-1>.html"          (same folder)
  East  (x+1, y):  "../<x+1>/<y>.html"
  West  (x-1, y):  "../<x-1>/<y>.html"
These are the data-href values. (Worked: from (1,0), N="1.html", S="-1.html",
E="../2/0.html", W="../0/0.html".)

TOOLING — STAY NEIGHBOUR-LOCAL. Do NOT grep every room to build name maps; that
will not scale past a few thousand rooms. Use `hoard.py` (same folder; see README.md):
  - `hoard.py next`     -> the next coord in writing order (maths only; next N
                           previews the order ahead, it does NOT let you write ahead)
  - `hoard.py plan`     -> briefing for the next room: the name it MUST take and the
                           exact answer for each wall, reading ONLY that room's
                           neighbours (and their neighbours) — never the whole grid
  - `hoard.py render room.json` -> render + save ONE room and advance the LAST ROOM
                           line. Takes ONE room and rejects a file holding more than
                           one — the one-at-a-time rhythm, enforced.
  - `hoard.py verify`   -> local crossword check of that room + its neighbours
The render template is byte-identical to the skeleton in section 9; you only author
content (name, desc, prose, four answers, four sets of riddle lines).


3. THE TWO AXES  (the "spectrum" — what kind of word belongs where)
-------------------------------------------------------------------
  x  =  NATURAL (west, -)  <-->  WROUGHT (east, +)
  y  =  TANGIBLE (south,-) <-->  INTANGIBLE (north, +)

  west  / natural   : made by no hand — river, frost, root, stone, seed, tide
  east  / wrought   : made by a hand  — key, bell, coin, clock, blade, nail
  south / tangible  : you can touch it — stone, bone, coin, ash, blade
  north / intangible: you cannot      — echo, wind, name, silence, hour, debt

So the four corners are four kinds of answer:
  SW natural+tangible (stone, root)    SE wrought+tangible (bell, coin)
  NW natural+intangible (wind, frost)  NE wrought+intangible (name, hour)

Choose a room's name to suit the quadrant it sits in. The palette engine
(rooms.js) tints each room from its (x,y) automatically, so a well-placed name
also lands in the right colour. The origin seed already lays this out: KEY at
centre, ECHO north (intangible), BELL east (wrought), STONE south (tangible),
RIVER west (natural).


4. DIFFICULTY BY DISTANCE — BANDED AND ENFORCED
-----------------------------------------------
Difficulty is NOT a vibe that creeps up at random — it is a step function of
one number: d = the straight-line distance from (0,0), d = sqrt(x*x + y*y).
That is the SAME number that fixes the writing order (section 2), so a room's
difficulty is known before a word of it is written. Read the band, write to the
band. Six bands span the world from the threshold to the rim:

  BAND          d range        register / what a riddle may do
  ----          -------        -------------------------------
  0 Threshold   d = 0           the origin only. The plainest riddle in the
                                world ("teeth but cannot bite"). One object, one
                                turn, <=4 lines.
  1 Approach    0 <  d <=  100  a child could get it. Concrete everyday objects,
                                plain words, classic folk riddles, <=4 lines.
  2 Near Hoard  100 <  d <= 120 solid folk riddles. First person, ONE kenning
                                allowed, still a touchable object, <=5 lines.
  3 Deep Hoard  120 < d <= 140  kennings are the norm; one real turn or paradox.
                                The answer may be a common abstraction (echo,
                                hour, debt), <=6 lines.
  4 Far Reaches 140 < d <= 149  layered kennings, deliberate misdirection, a
                                two-step solve. Answers are ideas, not objects,
                                <=6 lines.
  5 The Rim     149 < d < 212   the hardest standard riddles: dense, gnomic,
                                Exeter-Book obscurity, answers that are concepts.
  --- The four corners (d = 212.13) are their own apex; see section 12. ---

FOUR ANTI-DRIFT RULES (this is the "enforced" part):
  i.   CEILING & FLOOR. A riddle may never be harder than its band's ceiling
       nor easier than its floor. Concretely: no room is harder than ANY room
       in a strictly outer band, and none is easier than any room strictly
       inward. Difficulty only ever rises outward — it never dips back.
  ii.  MATCH A SIBLING. Before writing a room, open one ALREADY-WRITTEN room in
       the same band (nearest by d) and match its register, line count, and kind
       of answer. A band holds its line only if its rooms sound alike.
  iii. SELF-TEST AT THE BAND. The cold-read test (section 8) is judged AT the
       band: an Approach riddle a clever adult finds trivial is correct; a Rim
       riddle a clever adult finds merely "nice" is too easy — push it.
  iv.  THE WORD MUST FIT THE BAND, NOT JUST THE CLUE. The hardest part of a
       riddle is the ANSWER WORD itself: a clue can only retrieve a word the
       solver ALREADY KNOWS — no wording, however clean, can pull out a word they
       have never met. So a tidy clue NEVER rescues a too-hard answer. Every time
       you name a free cell (section 5) you are making a difficulty choice; the
       word must sit at the band's register or the whole room breaks the band, no
       matter how fair the riddle reads. Concretely:
       - APPROACH test — RECALL, not recognition: would an eight-year-old say the
         word UNPROMPTED? If they would only recognise it, or you would have to
         define it, it is too hard. Take the plainest everyday word that fits the
         cell; prefer the common object over the exact/technical term. Real swaps
         this rule already forced (left = WRONG for Approach, right = right):
           chisel→knife · lathe→ruler · rivet→pin · mallet→brush · rafter→fence ·
           scythe→bucket · gorse→grass · lichen→leaf · kelp→weed · heather→daisy ·
           couplet→word · epic→poem · haiku→story · serenade→joke · fanfare→cheer ·
           slumber→nap.
       - BANNED at Approach (these are Deep-Hoard-and-outward registers): trade or
         workshop jargon (lathe, rivet, scythe), verse/music terms (couplet,
         sonnet, ode, psalm, haiku, octave, refrain), naturalist or regional names
         of plants and rocks (gorse, lichen, bracken, kelp, shale, silt), and
         archaic or poetic synonyms (zephyr, murk, eve). Vocabulary climbs ONLY as
         d climbs — these words belong in bands 3-5, not at the threshold.
       - You may NOT rename an older room that already bears a too-hard name (the
         crossword forbids it, section 6a) — but never ADD to the drift: every new
         free cell you name must pass the test above. One inherited mistake does
         not license another.

Because rooms are written closest-first, you finish a whole ring before the next
begins, so the wall between bands stays clean. Never let a far room drift easy
because it was fun to write, nor a near room turn cruel because you had a clever
idea — the number d decides, not the mood.


5. THE NAMING RULE
------------------
A room's name is EXACTLY one word or one number. It must be:
  - unambiguous (one obvious thing the riddles can point to),
  - ASCII, no accents (matching is exact; "café" would demand the accent),
  - lowercase in data-answer; the displayed <h1 class="room-name"> may be
    capitalised ("Key", "Echo", "7"),
  - AT THE BAND'S READING LEVEL. When you name a free cell, the word itself must
    pass the band's word-familiarity test (section 4, anti-drift rule iv). At
    Approach that means a plain everyday word a child would say unprompted — never
    trade, verse, or naturalist jargon. The name is a difficulty choice as much as
    the riddle is: pick the plainest word that fits the cell and its quadrant.
Numbers are welcome (e.g. a riddle whose answer is 7, or 12).


6. THE 2D-CROSSWORD RULE  (the heart of the work)
-------------------------------------------------
This is the one constraint that makes the hoard hold together. When you write
room (x,y):

  a. Its OWN NAME is the answer to all four neighbours' riddles that face it.
     So the moment any neighbour pointing at (x,y) is written, this room's name
     is fixed. NEVER rename a room that a written neighbour already points to.

  b. You write FOUR riddles, one per wall, whose answers are the four NEIGHBOUR
     names:
       - Neighbour ALREADY WRITTEN: open its file, read its <h1 class="room-name">,
         and write a riddle that resolves to that exact word. You may not rename it.
       - Neighbour NOT YET WRITTEN: your riddle's answer DEFINES that future
         room's name. When you later write that room, it must take that name and
         must carry a facing riddle back whose answer is THIS room's name.

  c. The four answers within one room should be DISTINCT — don't let two walls
     share a word.

  d. Diagonals are shared. A cell like (1,1) is the east neighbour of (0,1) AND
     the north neighbour of (1,0); both must name it identically. Before naming
     an unwritten neighbour, check whether another already-written room also
     borders it and has already fixed its name. (In the seed: NAME, COIN, WIND,
     ROOT are each fixed by two of the five rooms.)

Practical loop for one room (run `hoard.py plan` to do steps 1-2/4 for the next
room, neighbour-locally):
  1. Read every existing neighbour (up to 4 files). Note their names.
  2. Decide this room's name (consistent with any neighbour already facing it).
  3. Write a short prose paragraph (see 7) and the four riddles (see 8).
  4. For written neighbours, the riddle answer = their name. For unwritten ones,
     pick a name fitting that quadrant AND the band's reading level (section 4,
     rule iv: at Approach, the plainest everyday word a child would say); the
     answer = that name.
  5. Before saving, run the band check: is every answer a word the band's solver
     already knows (not just one a clean clue points at)? If any answer is trade,
     verse, or naturalist jargon at Approach, swap it for the plainest synonym.
  6. Save, update rooms-map.txt, then go to the next coordinate.


7. THE PROSE
------------
Keep a short atmospheric paragraph (about 50-90 words) above the riddles, in
second person, present tense, that meditates on the room's word and its place
on the axes. It earns the first-paragraph drop cap and sets mood — but the
riddles are the room. Don't write the old 200-300 word chapters; the focus has
moved from story to puzzle.


8. RIDDLE CRAFT
---------------
  - One unambiguous solution, and it is the neighbour's exact name.
  - Voice to match the world: the Exeter Book / Hobbit register — first person
    ("I have a tongue but cannot taste..."), paradox, kennings, plain old words.
  - 2-6 short lines. Rhyme is welcome but never at the cost of a clean answer.
  - Test it cold: could a fair reader land on a DIFFERENT single word? If yes,
    tighten it until only the intended name fits.
  - Test it cold a SECOND way: is the answer a word the band's solver already
    holds? A clue can point at a word but never teach one. At Approach, if a
    plainer synonym fits the cell the answer is wrong until you use it (knife, not
    chisel; weed, not kelp). See section 4, anti-drift rule iv.
  - Numbers: count things the world counts (days, seasons, points of a compass).

10. THE PLAINTEXT TRADE-OFF (known, chosen)
-------------------------------------------
Answers live in plain text in data-answer, so anyone can View Source and peek.
This was chosen for simplicity over secrecy. It is intentional, not a bug. If
secrecy is ever wanted, hash the answers and compare hashes in rooms.js.


11. WORKED EXAMPLE — THE ORIGIN SEED
------------------------------------
        (0,1) ECHO
          |
(-1,0) RIVER — (0,0) KEY — (1,0) BELL
          |
       (0,-1) STONE

  (0,0) KEY      N->echo  E->bell  S->stone  W->river
  (0,1) ECHO     N->silence  E->name  S->key  W->wind
  (1,0) BELL     N->name  E->clock  S->coin  W->key
  (0,-1) STONE   N->key  E->coin  S->bone  W->root
  (-1,0) RIVER   N->wind  E->key  S->root  W->sea

KEY's east riddle (answer BELL):
  "I have a tongue but cannot taste, / a mouth that never eats; /
   I speak just once, and only when / a hammer-stroke me meets."
BELL's west riddle, facing back (answer KEY):
  "I am cut with teeth that never chew, / I wear a ring but not a hand; /
   turn me once, and I undo / the strongest lock in all the land."
That pair — two riddles across one shared wall, each answering the other room's
name — is the whole pattern. Build outward, one room at a time.


12. THE FOUR CORNERS — THE EDGE OF THE WORLD  (the endgame secret)
------------------------------------------------------------------
The world is a bounded square: every axis runs -150..+150 (there are exactly
301 x-folders, -150..150, and the palette clamps there). So the grid has four
true corners — the four cells farthest from the origin, d = 212.13, the global
maximum difficulty:

  NW (-150, 150) natural+intangible        NE (150, 150) wrought+intangible
                          \               /
                           the origin (0,0)
                          /               \
  SW (-150,-150) natural+tangible          SE (150,-150) wrought+tangible

These four rooms are special in three ways:

  a. THEY SPELL A SENTENCE. Each corner's NAME is one word, and the four words
     together read:   WORDS  OPEN  ALL  WALLS  — the thesis of the whole hoard,
     the reward for the one who finishes the world. Each word sits in the corner
     whose quadrant fits it (only one ordering of the four is a sentence, so a
     finisher reassembles it unaided):
        NE  words   wrought+intangible : language, the made/spoken word
        SE  walls   wrought+tangible   : the built, touchable thing
        SW  all     natural+tangible   : the whole solid ground, every thing
        NW  open    natural+intangible : the airy, unwalled, ungraspable state
     This is the ONE sanctioned exception to "a name is a concrete quadrant
     noun" (section 5): at the apex the sentence comes first.

  b. TWO WALLS ARE SEALED. A corner touches the rim of the world: two of its
     four walls face off-grid (beyond +-150). Those are NOT doors — they are the
     edge of creation, authored as <span class="wall ... is-rim"> with NO riddle
     form. Only the two INWARD walls carry riddles (among the hardest written),
     pointing at the corner's two inward neighbours, named here:
        NE words : S (150,149)  = hour    W (149,150)  = rune
        SE walls : N (150,-149) = gate    W (149,-150) = nail
        SW all   : N (-150,-149)= loam    E (-149,-150)= ore
        NW open  : S (-150,149) = mist    E (-149,150) = hush
     Whoever one day writes those neighbour rooms must carry a facing riddle back
     whose answer is the corner's word — the crossword rule (section 6) reaches
     even here.

  c. NOT REACHABLE BY NORMAL PLAY UNTIL THE GRID IS FINISHED. A corner is only
     walked into by solving the chain of rooms that leads out to it — which
     exists only once the whole grid is written. Until then its inward neighbours
     are undreamt (404) and there is no legitimate path in. We do not, and
     cannot, enforce this against URL-poking or View-Source (the plaintext
     trade-off, section 10) — it is a rule of fair play, documented here, not a
     lock.

OUT-OF-ORDER, ON PURPOSE. The corners are written NOW, ahead of the closest-
first progression — planted flags, not part of the contiguous blob growing from
the origin. They do NOT advance the LAST ROOM frontier in rooms-map.txt (which
still tracks only the unbroken run from 0:0); they are listed there separately.
The next NORMAL room is still the closest unwritten coordinate to (0,0), exactly
as if the corners were not there.
