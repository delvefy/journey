JOURNEY — THE RIDDLE-HOARD — ROOM TRACKER
=========================================

HOW TO WRITE THE NEXT ROOM
  - Write rooms ONE AT A TIME, never in batches: write the room, save the HTML,
    update the LAST ROOM line below, and ONLY THEN start the next room. Saving each
    room before beginning the next is what makes the work safe to interrupt.
  - "Write the next N rooms" means repeat that one-room loop N times (write, save,
    update tracker, proceed) — NOT write N at once, and NOT stop after one. "Write
    the next room" is just N = 1.
  - The next room is the unwritten coordinate CLOSEST to the origin (0,0):
    smallest straight-line distance; ties broken clockwise from north
    (N, NE, E, SE, S, SW, W, NW).
  - Each room IS a single-word/number answer; its four boxes hold riddles whose
    answers are the four NEIGHBOUR names. Read existing neighbours first and match
    their names exactly (the 2D-crossword rule). Full rules: see write.txt.
  - Difficulty is BANDED by distance d = sqrt(x*x + y*y) and enforced — write to
    the band, match a written sibling, never let it drift (write.txt section 4).
  - Duplicate names ARE allowed (finite per-band vocabulary) but policed by hoard.py:
    no twin (same name as any of the 8 neighbours), no clone (same name + same four
    neighbours), same-name rooms >= D_MIN apart. render refuses, verify flags. See
    write.txt section 5; the index lives in tools/names.json (rebuild: hoard.py reindex).
  - Save it as rooms/<x>/<y>.html, then update the LAST ROOM line below.
