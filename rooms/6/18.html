Code

You are a code - a clever set of rules for turning plain words into a secret, or back again. No tree grew you; a sharp mind made you, swapping each letter for another, or for a dot and a dash, so a message can travel past prying eyes. You cannot be held, only cracked. Spies live by you, machines think in you, and a child with a decoder ring feels, for one afternoon, like the keeper of a hidden door.
